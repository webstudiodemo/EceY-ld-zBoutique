# Ecce Yıldız Boutique

GitHub Pages üzerinde çalışan, Türkçe premium butik demo sitesi.

## Kullanım

index.html dosyasını GitHub Pages ile yayınlayın. style.css ve script.js aynı dizinde bulunmalıdır. GSAP, ScrollTrigger ve Lenis CDN üzerinden yüklenir.

## Önemli

Ürün isimleri ve fiyatları Shopier mağazasından alınmıştır (9 Ekim 2026). Stok, beden, taksit ve sipariş işlemleri örnektir. Ödeme formu gerçek ödeme almaz; kart bilgilerini bir sunucuya iletmez. Görseller Shopier CDN bağlantılarıdır ve mağaza/üçüncü taraf kullanım izinleri yayın öncesinde doğrulanmalıdır.
